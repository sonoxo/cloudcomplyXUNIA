# cloudcomply CLI Reference

cloudcomply has two modes: an interactive TUI dashboard (the default, no args) and a headless reporting mode for scripting and CI. This doc covers the command-line surface; see [README.md](README.md) for install/build instructions.

---

## Commands

### `cloudcomply`

Launches the interactive TUI dashboard. Equivalent to running with no subcommand.

```bash
cloudcomply
```

See [Using the TUI](#using-the-tui) below.

### `cloudcomply report nist`

Generates a NIST SP 800-53 findings report to stdout, with no interactive UI — suitable for CI pipelines or piping into other tools.

```bash
cloudcomply report nist [--format table|json]
```

| Flag | Default | Description |
|------|---------|-------------|
| `--format` | `table` | Output format: `table` (human-readable) or `json` (machine-readable) |

**Table output** (default):

```bash
cloudcomply report nist
```

```
CONTROL   TITLE                              STATUS  SEVERITY  ACCOUNTS  RMF_STEP   MIN_IL
AC-2      Account Management                 FAILED  HIGH      12        Assess     IL2
AC-2(1)   Auto Temp/Emergency Accounts       PASSED  LOW       0         Monitor    IL4
...
```

**JSON output** (for scripting):

```bash
cloudcomply report nist --format json
```

```json
[
  {
    "control_id": "AC-2",
    "title": "Account Management",
    "family": "AC",
    "status": "FAILED",
    "severity": "HIGH",
    "accounts_affected": 12,
    "rmf_step": "Assess",
    "min_impact_level": "IL2"
  }
]
```

The `json` output is a stable field contract — pipe it into `jq`, a CI gate, or a report generator without worrying about field names shifting between releases:

```bash
cloudcomply report nist --format json | jq '[.[] | select(.status == "FAILED")]'
```

An invalid `--format` value exits non-zero with an error on stderr, no usage dump:

```bash
$ cloudcomply report nist --format bogus
unsupported format "bogus" (want: table, json)
$ echo $?
1
```

> **Demo data today:** `report nist` currently always reads from cloudcomply's built-in demo dataset — there's no live AWS call yet. Live Security Hub integration is planned; once it lands, this command's output will reflect your real AWS Organization, but the command and flags themselves won't change.

### `cloudcomply --version` / `-v`

Prints the build version, commit, and build date (populated from release builds; shows `dev`/`none`/`unknown` for local builds).

```bash
$ cloudcomply --version
cloudcomply version dev (commit none, built unknown)
```

### `cloudcomply --help` / `-h`

Works at every level — `cloudcomply --help`, `cloudcomply report --help`, `cloudcomply report nist --help` — and lists available subcommands and flags.

### `cloudcomply completion`

Auto-generated by Cobra — prints a shell autocompletion script (bash/zsh/fish/PowerShell). Run `cloudcomply completion --help` for setup instructions for your shell.

## Using the TUI

Run `cloudcomply` with no arguments to launch the full-screen dashboard.

### Dashboard

The landing screen shows your org name, account count, overall NIST 800-53 compliance score, and a DoD SRG Impact Level–scoped readiness score. From here, use the main menu to:

- **Run Full NIST Compliance Scan** — re-run the scan (demo mode: instant, shows a status message)
- **Browse Findings by Control Family** — opens the findings browser
- **Generate Threat Model** — coming soon
- **View Best Practices Report** — coming soon
- **Quit**

### Findings Browser

A sortable table of every finding, with two independent filter tabs:

- **Family** (`←`/`→` or `h`/`l`) — filter to a single control family (AC, AU, CM, IA, SC, SI) or `ALL`
- **Impact Level** (`[`/`]`) — filter to controls required at or below a target DoD SRG Impact Level (IL2/IL4/IL5/IL6), or `ALL`

Pass/fail counts update live as you change filters.

### Keybindings

| Key | Action |
|-----|--------|
| `↑` / `k` | Move up |
| `↓` / `j` | Move down |
| `←` / `h` | Previous control family filter |
| `→` / `l` | Next control family filter |
| `[` | Previous DoD SRG impact level filter |
| `]` | Next DoD SRG impact level filter |
| `Enter` | Select / open |
| `Esc` / `q` | Back / quit |
| `Ctrl+C` | Force quit |
